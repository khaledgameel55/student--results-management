# نظام إدارة وتحليل نتائج الطلاب

نظام بسيط ومباشر لإدارة وتحليل نتائج الطلاب باستخدام JavaScript، مصمم للعمل عبر Console. المشروع يركز على حساب النتائج الأكاديمية، استخراج التقديرات، وتحديد حالة الطلاب النهائية مع إمكانية تطبيق سياسة الرأفة على الطلاب المتعثرين.

## الميزات

- إنشاء كيان Student يحتوي على:
  - رقم الطالب
  - اسم الطالب
  - درجاته
  - نسبة الحضور
- حساب المتوسط الحسابي للطالب
- تحديد التقدير الأكاديمي بناءً على المتوسط
- تحديد الحالة النهائية: ناجح أو يحتاج مراجعة
يفتح هذا الرابط بعد اكتمال النشر:
- تطبيق أسلوب الرأفة عبر زيادة المتوسط بمقدار 5 درجات
https://jalaljamal24.github.io/student-results-management/
- تنفيذ اختبارات للتحقق من دقة المنطق

## التقنيات المستخدمة

- JavaScript
- Node.js
- اختبار مبني على `node:test`

## التشغيل

### 1) تشغيل التطبيق

```powershell
cd "C:\Users\jalal\Desktop\نظام إدارة وتحليل نتائج الطلاب"
set PATH=C:\Program Files\nodejs;%PATH%
chcp 65001
node src/index.js
```

### 2) تشغيل الاختبارات

```powershell
cd "C:\Users\jalal\Desktop\نظام إدارة وتحليل نتائج الطلاب"
set PATH=C:\Program Files\nodejs;%PATH%
npm test
```

### 3) عرض النتائج في Console المتصفح

ثبّت الاعتماديات مرة واحدة:

```powershell
npm install
```

ثم شغّل خادم التطوير:

```powershell
npm run dev
```

افتح رابط الخادم المحلي الذي يظهر في الطرفية، ثم افتح Developer Tools وانتقل إلى تبويب Console لرؤية تقرير الطلاب ومخرجات الرأفة. لا تفتح `index.html` مباشرة كملف محلي، لأن استيراد ملفات JavaScript كـ modules يحتاج إلى خادم محلي.

للتأكد من جاهزية نسخة البناء:

```powershell
npm run build
```
