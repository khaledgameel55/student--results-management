# نظام إدارة وتحليل نتائج الطلاب

تطبيق تعليمي باستخدام JavaScript يعرض تقرير الطلاب وتحليل لجنة الرأفة داخل صفحة متصفح، ويطبع النتائج أيضاً في Console. يطبّق مفاهيم البرمجة كائنية التوجه ودوال المصفوفات `map` و`filter` و`reduce`.

## المتطلبات

- Node.js 18 أو أحدث، أو متصفح حديث.

## التشغيل

### عرض النتائج في صفحة المتصفح

افتح ملف `index.html` مباشرةً في متصفح حديث. ستظهر التقارير في الصفحة، وتظهر التفاصيل أيضاً في أدوات المطور ضمن Console.

### التشغيل من سطر الأوامر

```bash
npm start
```

يمكن أيضاً تشغيله مباشرةً:

```bash
node index.js
```

يمكن أيضاً تشغيل `index.js` من أدوات المطور في المتصفح، لكن فتح `index.html` يعرض النتائج في واجهة الصفحة.

## قواعد النظام

- يُحسب متوسط الطالب من درجات المواد الثلاث باستخدام `reduce`.
- تُحدّد التقديرات: A من 90، B من 80، C من 70، D من 60، E من 50، وF لما دون ذلك.
- النجاح يتطلب متوسطاً لا يقل عن 50 وحضوراً لا يقل عن 75%.
- تشمل لجنة الرأفة الطلاب الذين يتراوح متوسطهم بين 40 و49، وتضيف خمس درجات إلى متوسط كل منهم لأغراض التقرير دون تغيير درجاتهم الأصلية.
- يُحسب متوسط المستفيدين بعد الرأفة، مع التعامل مع حالة عدم وجود طلاب متعثرين.

## بيانات التجربة

يحتوي `index.js` على أربعة طلاب تجريبيين، بينهم طالبان متوسطاهما ضمن نطاق لجنة الرأفة. يمكن تعديل بياناتهم في `studentsList`.
