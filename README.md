# نظام إدارة وتحليل نتائج الطلاب

تطبيق JavaScript لإدارة نتائج الطلاب، حساب المتوسط والتقدير والحالة النهائية، وتحديد الطلاب المتعثرين وتطبيق درجات الرأفة. يعرض التطبيق تقريرًا في الصفحة وفي Console المتصفح.

## المتطلبات

- Node.js 20.19 أو أحدث، أو 22.12 أو أحدث
- npm

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح رابط localhost الذي يظهر في الطرفية. لعرض سجل التنفيذ، افتح أدوات المطور في المتصفح ثم تبويب Console.

لتشغيل التقرير في طرفية Node.js:

```bash
npm start
```

## الاختبارات والبناء

```bash
npm test
npm run build
```

## النشر

عند الدفع إلى فرع `main`، يبني GitHub Actions الموقع وينشره على GitHub Pages. رابط الموقع يظهر في صفحة Actions بعد اكتمال النشر.

## قواعد النتائج

- المتوسط هو مجموع الدرجات مقسومًا على عدد المواد.
- التقديرات: A من 90، B من 80، C من 70، D من 60، E من 50، وما دون ذلك F.
- النجاح يتطلب متوسطًا لا يقل عن 50 وحضورًا لا يقل عن 75%.
- تُضاف 5 درجات إلى متوسط الطالب الذي يقع متوسطه بين 40 و49.
